**Glitching** — the one word an agent blurts when its brain freezes mid-task: not an error code, not an apology, just the machine narrating its own malfunction out loud while it has no idea what to do next.

Entered in [The Agent's Uh-Oh](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4) on make.fun.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (and a byte-identical copy to `entry.txt` in the repo root when writable). Deterministic, no network, no randomness.
